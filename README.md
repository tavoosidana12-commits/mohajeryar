# مهاجریار | بستهٔ استقرار Liara

پروژهٔ فارسی و راست‌چین Next.js 14 با APIهای نمونه و اتصال اختیاری PostgreSQL.

## راه‌اندازی محلی
```bash
npm install
npm run dev
```

## پیکربندی Liara
- `DATABASE_URL`: رشتهٔ اتصال PostgreSQL؛ اگر خالی باشد APIها به پاسخ fallback بدون دیتابیس ادامه می‌دهند.
- اتصال SSL برای دامنه‌های Liara (یا `DATABASE_SSL=true`) فعال می‌شود. می‌توان با `PGSSLMODE=verify-full` اعتبارسنجی گواهی را فعال کرد؛ حالت پیش‌فرض Liara برای سازگاری با گواهی‌های عمومیِ مدیریت‌شده `rejectUnauthorized=false` است.
- اجرای نخست درخواست API به‌طور idempotent جداول و seedها را می‌سازد. قفل advisory تراکنشی از اجرای همزمان چند instance جلوگیری می‌کند و خطا در درخواست بعدی قابل retry است.
- `LIARA_AI_API_KEY` و در صورت نیاز `LIARA_AI_ENDPOINT` و `LIARA_AI_MODEL` برای گزارش هوش مصنوعی اختیاری‌اند.

## داده‌های رسمی و محدودیت‌ها
Seedها فقط از گروه‌ها، کشورها و URLهای رسمیِ از پیش موجود در `src/lib/constants.ts` استفاده می‌کنند. قوانین به‌صورت راهنمای بررسی منبع رسمی نگهداری شده‌اند؛ `min_score` و `processing_time` عمداً خالی‌اند چون معیار و زمان واحد و معتبر برای همهٔ زیرشاخه‌ها از این URLها قابل اثبات نیست. این بسته ادعای مجموعهٔ جامعِ قوانین رسمی همهٔ ویزاها را ندارد. هنگام گزارش، ماژولِ همان کشور و گروه از DB خوانده می‌شود و دادهٔ ناموجود نباید حدس زده شود.

## هشدار عملیاتی مهم
`/api/unlock-report` در نسخهٔ پایه صرفاً وجود `payment_ref` غیرخالی را بررسی می‌کند و آن را با درگاه پرداخت اعتبارسنجی نمی‌کند. پرداخت واقعی/امن را پیش از فروش به callback معتبر درگاه و تطبیق سفارش متصل کنید. این اپلیکیشن ابزار اطلاعاتی است، نه مشاورهٔ حقوقی یا تضمین صلاحیت مهاجرت.

برای انتشار محلی: `npm run build && npm run start` (پورت ۳۰۰۰).
